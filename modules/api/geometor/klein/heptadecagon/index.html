geometor.klein.heptadecagon¶

Exact Gaussian period tower and von Staudt–Schröter–Klein construction of the regular 17-gon.

Implements Felix Klein’s Famous Problems of Elementary Geometry, Part I, Chapter IV (§§ 1–9, EN pp. 24–41 / DE S. 19–32):

  1. Gaussian Period Quadratic Tower (§§ 1–6): Using the primitive root \(g = 3 \pmod{17}\), partitions the 16 primitive 17th roots of unity into:

    • Two 8-periods \(x_1, x_2\) (DE: \(\eta_0, \eta_1\)) solving \((\xi): x^2 + x - 4 = 0\);

    • Four 4-periods \(y_1, y_2\) (DE: \(\eta'_0, \eta'_1\)) solving \((\eta): y^2 - x_1 y - 1 = 0\), and \(y_4, y_3\) (DE: \((\eta'_0), (\eta'_1)\)) solving \((\eta'): y^2 - x_2 y - 1 = 0\), satisfying Klein’s inequality chain \(y_3 < y_2 < y_4 < y_1\) and radical-dependence identity \(\sqrt{x_1^2 + 4}\,\sqrt{x_2^2 + 4} = 2\sqrt{17}\);

    • Eight real 2-periods \(z_1, \dots, z_8\) (\(z_1 = 2\cos(2\pi/17)\)) with \(z_1, z_2\) solving \((\zeta): z^2 - y_1 z + y_4 = 0\).

  2. Poncelet–Steiner Single-Circle Construction (von Staudt 1842 / Schröter 1872 / Klein §§ 8–9): Solves all four quadratic equations \((\xi), (\eta), (\eta'), (\zeta)\) geometrically inside geometor.model.Model (auto_intersect=False) using only straightedge lines and a single fixed circle \(C_0: x^2 + y(y - 2) = 0\), then inscribes all 17 exact regular heptadecagon vertices V0..``V16`` on \(C_0\) via Steiner straightedge parallels—using len(model.circles) == 1 and zero float / sp.Float coordinates!

geometor.klein.heptadecagon.construct_gauss_17gon_periods(model: geometor.model.Model | None = None, *, inscribe_polygon: bool = True, add_sides: bool = True) → Gauss17GonPeriods¶

Construct Gauss’s 17-gon period tower and Klein’s von Staudt–Schröter single-circle 17-gon.

Solves all four quadratic period equations \((\xi), (\eta), (\eta'), (\zeta)\) on the single fixed circle \(C_0: x^2 + y(y - 2) = 0\) (center C0c(0, 1), bottom O(0, 0), top A(0, 2)) using straightedge lines alone, and (when inscribe_polygon=True) inscribes all 17 exact regular heptadecagon vertices V0..``V16`` on \(C_0\) via Steiner’s straightedge parallel theorem—keeping len(model.circles) == 1 and 0 floats!

Parameters:

  • model – Optional existing Model (must have auto_intersect=False or will be configured with canonicalize_17). When None, creates a fresh Model("klein_von_staudt_17gon", logger=False, auto_intersect=False).

  • inscribe_polygon – If True (default), construct all 17 exact vertices V0..``V16``.

  • add_sides – If True (default) and inscribe_polygon=True, add the 17 polygon sides.

Returns:

A frozen Gauss17GonPeriods bundle containing the verified algebraic periods, minimal quadratic equations, and exact Model.
