geometor.klein¶

GEOMETOR • klein — Dual-treatise Book Codex & exact symbolic engine for Felix Klein.

Provides exact SymPy and geometor.model implementations accompanying:

  1. Famous Problems of Elementary Geometry (Vorträge über ausgewählte Fragen der Elementargeometrie, 1895; trans. W. W. Beman & D. E. Smith, 1897).

  2. A Comparative Review of Recent Researches in Geometry (“The Erlangen Program”) (Vergleichende Betrachtungen über neuere geometrische Forschungen, 1872; trans. M. W. Haskell, 1893).

geometor.klein.analyze_constructibility(poly_or_n: int | sympy.Integer | sympy.Poly | sympy.Expr) → ConstructibilityReport¶

Analyze compass-and-straightedge constructibility of a regular polygon, polynomial, or number.

Parameters:

poly_or_n –

  • int / sympy.Integer (\(n \ge 3\)): tests the regular \(n\)-gon via Euler’s totient \(\varphi(n) = 2^k\) and Fermat-prime factorization.

  • sympy.Poly or univariate sympy.Expr: factors over \(\mathbb{Q}\) and applies Klein’s degree-\(2^h\) criterion plus cubic-resolvent Galois check.

  • Closed-form algebraic or transcendental sympy.Expr (no free symbols): detects transcendence (\(\pi\), \(e\)) or computes the exact minimal polynomial over \(\mathbb{Q}\).

Returns:

A populated ConstructibilityReport with exact minimal polynomial, tower depth, and Galois/transcendence obstruction diagnosis.

geometor.klein.cubic_resolvent(quartic_poly: sympy.Poly, var: sympy.Symbol | None = None) → sympy.Poly¶

Return the exact depressed cubic resolvent \(R(t)\) of a degree-4 polynomial.

Depresses \(a_4 x^4 + a_3 x^3 + a_2 x^2 + a_1 x + a_0\) via \(x = y - a_3/(4a_4)\) into \(y^4 + p y^2 + q y + r\) and returns \(R(t) = t^3 - 2p t^2 + (p^2 - 4r) t + q^2\) over \(\mathbb{Q}\).

geometor.klein.cyclotomic_real_minimal_poly(n: int, var: sympy.Symbol | None = None) → sympy.Poly¶

Compute the exact minimal polynomial over \(\mathbb{Q}\) of \(u = 2\cos(2\pi/n)\).

For \(n \ge 3\), \(\Phi_n(z)\) has even degree \(\varphi(n) = 2d\) and is palindromic, so \(z^{-d}\Phi_n(z)\) is an integer polynomial of degree \(d\) in \(u = z + z^{-1} = 2\cos(2\pi/n)\). For \(n = 1, 2\), returns \(u - 2\) and \(u + 2\) respectively.

geometor.klein.circular_quadrance_cross_ratio(p1: sympy.geometry.Point2D, p2: sympy.geometry.Point2D, p3: sympy.geometry.Point2D, p4: sympy.geometry.Point2D) → sympy.Expr¶

Compute the Möbius-invariant 4-point quadrance cross-ratio \(\frac{Q(P_1,P_3)Q(P_2,P_4)}{Q(P_1,P_4)Q(P_2,P_3)}\).

Under any Euclidean similarity or any circle inversion \(P \mapsto O + R^2(P-O)/Q(O,P)\) (whose center \(O\) is distinct from \(P_1..P_4\)), the squared chord length transforms as \(Q(P_i', P_j') = R^4 Q(P_i, P_j) / [Q(O, P_i) Q(O, P_j)]\), so all four denominator factors \(Q(O, P_k)\) cancel identically! Furthermore, when \(A, B, C, D\) are collinear, this coincides with the square \((A, B; C, D)^2\) of the projective cross-ratio.

geometor.klein.verify_cayley_klein_additivity() → CayleyKleinReport¶

Prove symbolic additivity of Klein’s projective metric \(d(A, B) = c \log(A, B; I_1, I_2)\).

In Note V (On the So-Called Non-Euclidean Geometry) and § 10.2 of the Erlangen Program, Klein subsumes hyperbolic, elliptic, and parabolic metrics under projective geometry by adjoining an invariant second-degree Absolute (\(\Omega = 0\)). Along any line meeting the Absolute in \(I_1, I_2\), the cross-ratio multiplicativity \((A, B; I_1, I_2) \cdot (B, C; I_1, I_2) = (A, C; I_1, I_2)\) converts into exact geodesic distance additivity \(d(A, B) + d(B, C) = d(A, C)\).

geometor.klein.verify_erlangen_invariants() → ErlangenHierarchyReport¶

Execute an exact symbolic invariant audit across four groups of Klein’s Erlangen Program.

Applies four rational planar transformations to a shared exact rational point configuration:

  1. principal_similarity (Hauptgruppe, § 1): rational rotation \((3/5, 4/5)\), isotropic scaling \(5/2\), and translation \((3, -2)\).

  2. affine_shear (§ 2): equiaffine shear + translation \((x, y) \mapsto (x + 2y + 1, y - 3)\).

  3. projective_homography (§ 3): nonsingular projective collineation \((x, y) \mapsto \left(\frac{2x + y + 1}{x + y + 3}, \frac{x + 3y + 2}{x + y + 3}\right)\).

  4. moebius_circle_inversion (Geometrie der reciproken Radien, § 6): inversion in the circle centered at \(O_{\mathrm{inv}}(-1, -2)\) of squared radius \(R^2 = 5\).

geometor.klein.construct_gauss_17gon_periods(model: geometor.model.Model | None = None, *, inscribe_polygon: bool = True, add_sides: bool = True) → Gauss17GonPeriods¶

Construct Gauss’s 17-gon period tower and Klein’s von Staudt–Schröter single-circle 17-gon.

Solves all four quadratic period equations \((\xi), (\eta), (\eta'), (\zeta)\) on the single fixed circle \(C_0: x^2 + y(y - 2) = 0\) (center C0c(0, 1), bottom O(0, 0), top A(0, 2)) using straightedge lines alone, and (when inscribe_polygon=True) inscribes all 17 exact regular heptadecagon vertices V0..``V16`` on \(C_0\) via Steiner’s straightedge parallel theorem—keeping len(model.circles) == 1 and 0 floats!

Parameters:

  • model – Optional existing Model (must have auto_intersect=False or will be configured with canonicalize_17). When None, creates a fresh Model("klein_von_staudt_17gon", logger=False, auto_intersect=False).

  • inscribe_polygon – If True (default), construct all 17 exact vertices V0..``V16``.

  • add_sides – If True (default) and inscribe_polygon=True, add the 17 polygon sides.

Returns:

A frozen Gauss17GonPeriods bundle containing the verified algebraic periods, minimal quadratic equations, and exact Model.
