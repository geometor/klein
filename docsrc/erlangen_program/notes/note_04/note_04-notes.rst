Note IV: Manifoldnesses of Any Number of Dimensions — Critical Notes
====================================================================

.. rubric:: Mathematical :math:`n`-Manifolds vs. Higher-Dimensional Mysticism

Grassmann, Riemann, and Plücker Manifolds
-----------------------------------------

In Note IV, Klein sharply separates rigorous mathematics from popular spiritualist claims about a physical fourth dimension:

* **Pure Manifold Theory:** Founded by :person:`Grassmann <grassmann>` (*Ausdehnungslehre*, 1844) and :person:`Riemann <riemann>` (*Hypothesen*, 1854), :math:`n`-dimensional manifolds represent abstract systems of :math:`n` independent continuous parameters.
* **Plücker's Parameter Spaces:** :person:`Plücker <pluecker>` demonstrated that actual 3-space is already a 4-dimensional manifold if one takes the straight line or sphere as space-element!
